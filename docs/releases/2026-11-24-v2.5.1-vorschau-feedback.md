## Ablauf
1. `pnpm install --frozen-lockfile`, Build mit `WORKERS_CI=1 WORKERS_CI_BRANCH=main`.
2. Migration: Die Worker-Konfiguration verweist mit `migrations_dir` auf einen nicht vorhandenen Ordner `migrations`. Deshalb lief `wrangler d1 migrations list/apply` mit einer temporären Konfiguration, die nur die D1-Bindung enthielt und auf `drizzle/` zeigte. Die Konfiguration wurde danach gelöscht.
3. `wrangler versions upload` + `versions deploy`, danach `wrangler logout`.
