## Inhalt
- **Vision Engine:** Visionen laufen mit WebGL2-Nebel, wolkiger Bildkontur ohne sichtbare Kanten, Effektsprache je Visionstyp, frei stehender Typografie und Ton auf demselben Zeitplan. Ohne WebGL2 einfache Canvas-Darstellung.
- **Regie im Ersteller (Schritt 6):** neue Visionen mit Live-Bühne und Einstellungen je Bild (Brennpunkt, geschützter Kern, Größe, Platz, Text, Nachhall, Haltezeit), Eintauchen, Schlusssatz, Intensität, Farbfilter. Bestehende Visionen bleiben unverändert und zeigen „Regie einrichten“.
- **Bilder je Eintrag getrennt:** nur eigene Bilder offen, alle anderen in der eingeklappten Galerie.
- Details: `docs/alpha-2/VISION-ENGINE-INTEGRATION.md`.

## Ablauf
1. Separater, sauberer Checkout von `main` (`1b4bbe9`), `pnpm install --frozen-lockfile` mit pnpm 11.25.0.
2. Build mit `WORKERS_CI=1 WORKERS_CI_BRANCH=main`. Geprüft: Weiterleitung auf `dist/server/wrangler.json`, Produktionsbindungen, `keep_vars: true`, Engine-Chunk und Editor im Build.
3. `wrangler versions upload --name chronik-von-kleve --tag v2.5.5-1b4bbe9`, Bindungen der neuen Version mit der Vorversion verglichen (identisch).
4. `wrangler versions deploy 7e61c20b-…@100% --name chronik-von-kleve`.
5. Kein `wrangler logout`: Die Anmeldung bestand schon vor diesem Release und wurde nicht von Claude angelegt.
